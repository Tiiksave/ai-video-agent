
# AI Video Agent

وكيل ذكاء اصطناعي لإنشاء محتوى الفيديو وإدارة النشر والتعليقات.

## المزايا المخطط لها
- إنشاء أفكار وسيناريوهات للفيديو.
- تجهيز فيديوهات عمودية قصيرة.
- إضافة العناوين والوصف والترجمة.
- جدولة المهام السحابية.
- ربط المنصات عبر واجهاتها الرسمية.
- المساعدة في الرد على التعليقات.
- إعدادات لحماية مفاتيح API.

## التقنيات
- Python
- GitHub Actions
- FFmpeg
- Official platform APIs
